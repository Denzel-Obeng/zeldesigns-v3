# Zel Designs v3 — On-Scroll 3D Carousel Portfolio

A scroll-driven 3D carousel portfolio experience, inspired by Codrops.

## Live Demo
Deployed on Vercel as **zeldesigns-v3**.

## Features
- Smooth scroll with GSAP ScrollSmoother
- 3D rotating carousels driven by scroll
- Dramatic page transitions into project grids
- Character-level text animations with SplitText

## Local Development
```bash
npx serve .
```

## Assets
Place project images in the `assets/` folder (img1.png – img16.png).

Images sourced from the owner's Google Drive portfolio assets.
